    Editing Python Code

    KSML allows you to write custom logic in Python within your pipeline definitions. This guide explains the different approaches for organizing and editing Python code, from inline to fully externalized modules.

    Python Code Options

    1. Inline Code

    The simplest approach is to write Python code directly in your YAML file:

    Inline code example (click to expand) 
    # This example shows how to filter messages from a simple stream. Here we only let "blue sensors" pass and discard
# other messages after logging.

streams:
  sensor_source:
    topic: ksml_sensordata_avro
    keyType: string
    valueType: avro:SensorData
  sensor_filtered:
    topic: ksml_sensordata_filtered
    keyType: string
    valueType: avro:SensorData

functions:
  sensor_is_blue:
    type: predicate
    code: |
      if value == None:
        log.warn("No value in message with key={}", key)
        return False
      if value["color"] != "blue":
        log.warn("Unknown color: {}", value["color"])
        return False
    expression: True

pipelines:
  filter_pipeline:
    from: sensor_source
    via:
      - type: filter
        if: sensor_is_blue
      - type: peek
        forEach:
          code: log.info("MESSAGE ACCEPTED - key={}, value={}", key, value)
    to: sensor_filtered

    Use when: Logic is short and specific to one function.

    2. Global Code

    Define reusable functions in a globalCode block that can be referenced by multiple functions:

    Global code example (click to expand) 
    # This example shows how to filter messages from a simple stream using a function defined in globalCode.
# Here we only let "blue sensors" pass and discard other messages after logging.

streams:
  sensor_source:
    topic: ksml_sensordata_avro
    keyType: string
    valueType: avro:SensorData
  sensor_filtered:
    topic: ksml_sensordata_filtered
    keyType: string
    valueType: avro:SensorData

functions:
  sensor_is_blue:
    type: predicate
    globalCode: |
      def check_sensor_is_blue(value, key):
        if value == None:
          log.warn("No value in message with key={}", key)
          return False
        if value["color"] != "blue":
          log.warn("Unknown color: {}", value["color"])
          return False
        return True
    expression: check_sensor_is_blue(value, key)

pipelines:
  filter_pipeline:
    from: sensor_source
    via:
      - type: filter
        if: sensor_is_blue
      - type: peek
        forEach:
          code: log.info("MESSAGE ACCEPTED - key={}, value={}", key, value)
    to: sensor_filtered

    Use when: Multiple functions share common logic or utilities.

    A note on globalCode vs code

    Be aware that code in a globalCode block will be evaluated once, whereas code in a code block will be executed for every message. This means that for example import statements should not be in the code block, as doing so will carry a significant runtime overhead.
    One time initializations and import statements should always be in globalCode.

    3. Python Module Imports

    For advanced scenarios, import Python modules using globalCode:

    Python module import example (click to expand)

    YAML definition: 

    # This example shows how to filter messages from a simple stream. Here we only let "blue sensors" pass and discard
# other messages after logging.

streams:
  sensor_source:
    topic: ksml_sensordata_avro
    keyType: string
    valueType: avro:SensorData
  sensor_filtered:
    topic: ksml_sensordata_filtered
    keyType: string
    valueType: avro:SensorData

functions:
  module_import:
    globalCode: from test_filter_module import is_blue

  sensor_is_blue:
    type: predicate
    code: |
      return is_blue(value)
    expression: True

pipelines:
  filter_pipeline:
    from: sensor_source
    via:
      - type: filter
        if: sensor_is_blue
      - type: peek
        forEach:
          code: log.info("MESSAGE ACCEPTED - key={}, value={}", key, value)
    to: sensor_filtered

    Python module (test_filter_module.py): 

    def is_blue(val):
    """ Filter values in the stream with attribute 'color' having value 'blue'"""
    if val == None:
        return False
    if val["color"] != "blue":
        return False
    return True

def is_red(val):
    """ Filter values in the stream with attribute 'color' having value 'red'"""
    if val == None:
        return False
    if val["color"] != "red":
        return False
    return True

    Use when: You have a library of reusable functions or need to organize complex logic into modules.

    Note: When using module imports, configure the pythonModulePath parameter in runner configuration:

      # Python context configuration for module imports
  ksml:
    pythonContext:
      pythonModulePath: /ksml  # Directory where Python modules are located (mounted volume)

    Using KSML Runtime Objects in Modules

    log and metrics are available everywhere: in functions, in helper functions in globalCode, and in your own modules, without passing them as arguments. In a module, import them from the ksml module so your IDE knows them too, or use them without import:

    from ksml import log, metrics

def calculate_score(value):
    """Calculate score, logging under the name of the KSML function that called it."""
    risk_score = value.get("risk_score", 0)
    log.info("Calculated risk score: {}", risk_score)
    metrics.counter("scores_calculated").increment()
    return {"score": risk_score}

    log always logs under the logger name of the KSML function that is running, also when it is called from a helper function. Outside a KSML function, for example in module code that runs at import, it logs under the name ksml.

    State stores are different: a function only gets the stores it declares, so pass them to module functions as arguments.

    Passing State Stores

    For functions that use state stores, pass the store as an argument:

    functions:
  check_location:
    type: valueTransformer
    resultType: json
    code: |
      result = check_unusual_location(value, card_location_history)
    expression: result
    stores:
      - card_location_history

    In your Python module:

    from ksml import KeyValueStore

def check_unusual_location(value, store: KeyValueStore):
    """Check location using the state store."""
    card_id = value.get("card_id")
    history = store.get(card_id)
    # ... process and update store
    store.put(card_id, updated_history)
    return result

    Editor Support with the ksml Module

    KSML ships a ksml Python module that enables code completion and type checking in your IDE, and provides the actual types at runtime.

    Setting Up Code Completion

    KSML loads the ksml module into every Python context, so from ksml import ... works in inline code, globalCode and your own modules, without any setup. For code completion, let KSML write the module for its version next to your modules, or anywhere your IDE finds it:

    # With the Docker image
docker run --rm axual/ksml:latest --python-module > modules/ksml.py

# With the runner jar
java -jar ksml-runner.jar --python-module modules/ksml.py

    Without a file name, --python-module prints the module to the standard output. The first line of the file names the KSML version it belongs to, so run the command again after upgrading KSML. The module works in two modes:

    • At edit time: Provides Protocol classes for IDE code completion and type checking
    • At runtime: Imports the actual Java types via GraalVM

    At runtime, KSML always uses the ksml module it ships with. A ksml.py in your pythonModulePath is not loaded, so an outdated copy only affects your IDE.

    Simply import the types you need in your module:

    from ksml import PythonLogger, KeyValueStore, MetricsBridge

def my_function(value, log: PythonLogger, store: KeyValueStore):
    log.info("Processing value: {}", value)
    # Your IDE will provide full code completion for log and store

    Available Runtime Objects

    The ksml.py module provides type definitions for:

    Logger (PythonLogger)

    • log.trace(), log.debug(), log.info(), log.warn(), log.error()
    • Level checks: isTraceEnabled(), isDebugEnabled(), etc.

    Metrics (MetricsBridge)

    • metrics.counter(name) - Create/get a counter metric
    • metrics.meter(name) - Create/get a meter metric
    • metrics.timer(name) - Create/get a timer metric

    Processor Context (ProcessorContext)

    • context.forward(key, value, timestamp=None, headers=None, to=None) - Emit a record from a punctuator
    • context.currentSystemTimeMs(), context.currentStreamTimeMs(), context.applicationId(), context.taskId(), context.commit()

    State Stores

    The main store types are:

    • KeyValueStore - Simple key-value operations: get(), put(), putAll(), putIfAbsent(), delete(), range(), reverseRange(), all(), reverseAll(), prefixScan(), approximateNumEntries()
    • SessionStore - Session-windowed store: fetch(), findSessions(), put(), remove()
    • WindowStore - Time-windowed store: fetch(), fetchAll(), backwardFetch(), put(), all()

    Timestamped stores have the same methods, plus *WithTimestamp methods. See State Store Reference.

    Store methods that return many entries, like all(), return a StoreIterator. Use it in a for loop, a with block, or with next() and list(). See Reading Many Entries with Iterators.

    class StateStore(Protocol):
        """Base interface for state stores.

        Keys and values are converted to the keyType and valueType of the store when these are simple types: an int
        to any number type, a float to float or double, a str to string, a bool to boolean, and bytes or a list or
        tuple of ints from -128 to 255 to bytes. A value of another kind raises TypeError (also a float on an integer
        store, and a bool on a number store), an int out of range raises ValueError.
        A None value is not converted. A None key in a method that takes one key, such as get, put, putIfAbsent,
        putAll, delete or fetch, raises ValueError; None as a range bound means no bound. Stores with other types are
        not converted.
        """

        def name(self) -> str: ...
        def persistent(self) -> bool: ...
        def isOpen(self) -> bool: ...
        def flush(self) -> None: ...
        def close(self) -> None: ...

    class KeyValueStore(StateStore, Protocol):
        """Key-Value store interface"""

        def get(self, key: Any) -> Optional[Any]: ...
        def put(self, key: Any, value: Any) -> None: ...
        def putIfAbsent(self, key: Any, value: Any) -> Optional[Any]: ...
        def delete(self, key: Any) -> Optional[Any]: ...
        def range(self, keyFrom: Any, keyTo: Any) -> StoreIterator:
            """Entries from keyFrom to keyTo, both included. None means no bound."""
            ...
        def reverseRange(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        def all(self) -> StoreIterator: ...
        def reverseAll(self) -> StoreIterator: ...
        def prefixScan(self, prefix: str) -> StoreIterator:
            """Entries whose key starts with prefix. For stores with string keys.

            Raises TypeError if prefix is not a string, or the keyType of the store is not string.
            """
            ...
        def putAll(self, entries: Iterable[Union[Tuple[Any, Any], List[Any], Dict[str, Any]]]) -> None:
            """Writes (key, value) pairs or {"key", "value"} dicts. None deletes. A bad entry raises and writes nothing."""
            ...
        def approximateNumEntries(self) -> int: ...

    class SessionStore(StateStore, Protocol):
        """Session store interface.

        A session key is a dict with "key", "start" and "end" (int times in milliseconds); start may equal end.
        put and remove raise TypeError for a session key that is not a dict or a time that is not an int, and
        ValueError for a missing field, a None key, a time out of the long range, a negative start, or a start after
        the end.
        """

        def put(self, sessionKey: Dict[str, Any], value: Any) -> None: ...
        def remove(self, sessionKey: Dict[str, Any]) -> None: ...
        @overload
        def fetch(self, key: Any) -> StoreIterator: ...
        @overload
        def fetch(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        def fetchSession(self, key: Any, sessionStartTime: int, sessionEndTime: int) -> Any: ...
        @overload
        def backwardFetch(self, key: Any) -> StoreIterator: ...
        @overload
        def backwardFetch(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        @overload
        def findSessions(self, key: Any, earliestSessionEndTime: int, latestSessionStartTime: int) -> StoreIterator: ...
        @overload
        def findSessions(self, keyFrom: Any, keyTo: Any, earliestSessionEndTime: int, latestSessionStartTime: int) -> StoreIterator: ...
        @overload
        def backwardFindSessions(self, key: Any, earliestSessionEndTime: int, latestSessionStartTime: int) -> StoreIterator: ...
        @overload
        def backwardFindSessions(self, keyFrom: Any, keyTo: Any, earliestSessionEndTime: int, latestSessionStartTime: int) -> StoreIterator: ...

    class WindowStore(StateStore, Protocol):
        """Window store interface"""

        def put(self, key: Any, value: Any, windowStartTimestamp: int) -> None: ...
        @overload
        def fetch(self, key: Any, time: int) -> Optional[Any]: ...
        @overload
        def fetch(self, key: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        @overload
        def fetch(self, keyFrom: Any, keyTo: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        @overload
        def backwardFetch(self, key: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        @overload
        def backwardFetch(self, keyFrom: Any, keyTo: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        def fetchAll(self, timeFrom: int, timeTo: int) -> StoreIterator: ...
        def backwardFetchAll(self, timeFrom: int, timeTo: int) -> StoreIterator: ...
        def all(self) -> StoreIterator: ...
        def backwardAll(self) -> StoreIterator: ...

    class TimestampedKeyValueStore(StateStore, Protocol):
        """Timestamped Key-Value store interface.

        Methods without WithTimestamp in their name return the same results as on a KeyValueStore. Writes without
        a timestamp use the timestamp of the record that is being processed. The *WithTimestamp methods also
        return the timestamp: getWithTimestamp gives {"value", "timestamp"}, the iterators give entries with
        "key", "value" and "timestamp".
        """

        def get(self, key: Any) -> Optional[Any]: ...
        def getWithTimestamp(self, key: Any) -> Optional[Dict[str, Any]]: ...
        @overload
        def put(self, key: Any, value: Any) -> None:
            """Stores the value with the timestamp of the record that is being processed."""
            ...
        @overload
        def put(self, key: Any, value: Any, timestamp: int) -> None: ...
        @overload
        def putIfAbsent(self, key: Any, value: Any) -> Optional[Any]: ...
        @overload
        def putIfAbsent(self, key: Any, value: Any, timestamp: int) -> Optional[Any]: ...
        def putAll(self, entries: Union[Iterable[Tuple[Any, Any]], Iterable[Dict[str, Any]]]) -> None:
            """Like KeyValueStore.putAll; a dict entry may have a "timestamp". Default timestamp: the record's."""
            ...
        def delete(self, key: Any) -> Optional[Any]: ...
        def range(self, keyFrom: Any, keyTo: Any) -> StoreIterator:
            """Entries from keyFrom to keyTo, both included. None means no bound."""
            ...
        def rangeWithTimestamp(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        def reverseRange(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        def reverseRangeWithTimestamp(self, keyFrom: Any, keyTo: Any) -> StoreIterator: ...
        def all(self) -> StoreIterator: ...
        def allWithTimestamp(self) -> StoreIterator: ...
        def reverseAll(self) -> StoreIterator: ...
        def reverseAllWithTimestamp(self) -> StoreIterator: ...
        def prefixScan(self, prefix: str) -> StoreIterator:
            """Entries whose key starts with prefix. For stores with string keys.

            Raises TypeError if prefix is not a string, or the keyType of the store is not string.
            """
            ...
        def prefixScanWithTimestamp(self, prefix: str) -> StoreIterator: ...
        def approximateNumEntries(self) -> int: ...

        @overload

        @overload
        def backwardFetch(self, key: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        @overload

        @overload
        def backwardFetchWithTimestamp(self, keyFrom: Any, keyTo: Any, timeFrom: int, timeTo: int) -> StoreIterator: ...
        def fetchAll(self, timeFrom: int, timeTo: int) -> StoreIterator: ...

        def backwardFetchAll(self, timeFrom: int, timeTo: int) -> StoreIterator: ...
        def backwardFetchAllWithTimestamp(self, timeFrom: int, timeTo: int) -> StoreIterator: ...

# The classes below are used at runtime too: KSML wraps the Java proxies of store iterators and of the processor
# context in them. They hold no state besides the proxy, so one definition serves every thread of the application.

class KSMLStoreIterator:
    """Iterator of {"key", "value"} dicts ({"key", "value", "timestamp"} for *WithTimestamp).

    Closed when all entries are read, at the end of a with block, or when the KSML function returns. Python looks up
    __enter__ and __exit__ on the type, which a Java object can not offer, so this class passes the calls on to the
    Java proxy.
    """
    __slots__ = ("_proxy",)

    def __init__(self, proxy: Any) -> None:
        self._proxy = proxy

    def __iter__(self) -> KSMLStoreIterator:
        return self

    def __next__(self) -> Dict[str, Any]:
        return next(self._proxy)

    def __enter__(self) -> KSMLStoreIterator:
        return self

    def __exit__(self, *exc_info: Any) -> bool:
        self._proxy.close()
        return False

    def hasNext(self) -> bool:
        return self._proxy.hasNext()

    def next(self) -> Optional[Dict[str, Any]]:
        return self._proxy.next()

    def peekNextKey(self) -> Optional[Any]:
        return self._proxy.peekNextKey()

    def close(self) -> None:
        self._proxy.close()


class KSMLProcessorContext:
    """The processor context, injected into a punctuator as context.

    GraalPy passes no keyword arguments to Java methods, so this class takes them and calls the Java proxy by
    position. It only offers the methods below.
    """
    __slots__ = ("_proxy",)

    def __init__(self, proxy: Any) -> None:
        object.__setattr__(self, "_proxy", proxy)

    def __setattr__(self, name: str, value: Any) -> None:
        raise AttributeError("The context is read-only")

    def forward(self, key: Any, value: Any, timestamp: Optional[int] = None, headers: Optional[Any] = None, to: Optional[str] = None) -> None:
        self._proxy.forward(key, value, timestamp, headers, to)

    def commit(self) -> None:
        self._proxy.commit()

    def currentSystemTimeMs(self) -> int:
        return self._proxy.currentSystemTimeMs()

    def currentStreamTimeMs(self) -> int:
        return self._proxy.currentStreamTimeMs()

    def applicationId(self) -> str:
        return self._proxy.applicationId()

    def taskId(self) -> str:
        return self._proxy.taskId()


class KSMLLogger:
    """The log variable. It logs to the logger of the KSML function that is running, also when called from a helper
    function in globalCode or in your own module. Outside a KSML function, it logs to the logger named "ksml".
    """
    __slots__ = ()

    def getName(self) -> str:
        return _current_logger().getName()

    def isTraceEnabled(self) -> bool:
        return _current_logger().isTraceEnabled()

    def isDebugEnabled(self) -> bool:
        return _current_logger().isDebugEnabled()

# The logger name of the KSML function that is running. Every call sets it, and a context variable keeps it separate
# for each thread, because one Python context serves all stream threads.
_current_function: contextvars.ContextVar[str] = contextvars.ContextVar("ksml_current_function", default="ksml")
_logger_bridge: Any = None
_loggers: Dict[str, Any] = {}


def _current_logger() -> PythonLogger:
    name = _current_function.get()
    logger = _loggers.get(name)
    if logger is None:
        logger = _logger_bridge.getLogger(name)
        _loggers[name] = logger
    return logger


def _ksml_init(logger_bridge: Any, metrics_bridge: Any) -> None:
    """Called by KSML when it loads this module. Makes log and metrics available everywhere, also without import."""
    global _logger_bridge, metrics
    import builtins
    _logger_bridge = logger_bridge
    metrics = metrics_bridge
    builtins.log = log
    builtins.metrics = metrics_bridge


if not TYPE_CHECKING:

    metrics = None

    Best Practices

    1. Start inline, move to modules as complexity grows
    2. Use globalCode for shared utilities and helper functions
    3. Import modules when you need a library of reusable functions
    4. Pass state stores as arguments to module functions; log and metrics are available everywhere
    5. Use the ksml.py module for better IDE support and fewer runtime errors
    6. Keep functions pure - avoid side effects outside of logging and metrics
    7. Handle None values explicitly to prevent runtime errors

    Summary

    This guide covered approaches to organizing Python code in KSML:

    1. Inline code - Quick and simple for short logic
    2. Global code - Share utilities across multiple functions
    3. Module imports - Full Python module system for libraries

    Key points for module imports:

    • Use log and metrics directly, or import them from ksml; pass state stores as function arguments
    • Import types from the ksml module; copy ksml.py next to your modules for IDE support
